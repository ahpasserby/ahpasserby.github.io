Matlab - Matrix Laboratory（矩阵实验室）

为什么是 Matlab?

  1. 社群环境: 数学建模中MATLAB 被广泛使用, 所以教程, 源码都非常丰富易于学习

  2. 语法: 他本质上是一个新的编程语言, 需要代码手重新进行学习, 但是它对于数学极度友好, 专为数学而生

    • 语法极度接近数学公式：解线性方程组 Ax = b，你只需要敲 x = A \ b。这在大多数语言里需要好几行循环或调用复杂库。
    • “向量化”操作：对一万个数字进行运算，用 C++ 你得写 for 循环，在 MATLAB 里就是 y = sin(x)。代码量和出错概率指数级下降。

下载并安装 MATLAB

  1. 这整个过程不需要任何的代理访问

  2. 访问 MATLAB 官网 https://ww2.mathworks.cn/

  3. 点击Get MATLAB

  4. Creat Account - 创建新账号

  5. 填入校园邮箱, 点击 Next

  6. 创建你的账号 并且 接受邮箱验证码

  7. 点击下载

  8. 打开安装程序, 登录账号, 选择自己需要的库就行了

如果你被拒绝了 请尝试以下解决方法:

  • 更换(更正)网络环境,可以试一下使用国内的网络
  • 使用无痕模式
  • 更换浏览器 实在不行就用我们学校 BNBU 的提供的安装链接吧 (学校的网站访问之前关闭代理) 这个有效期似乎只有一个星期, 并且仅限 bnbu 学生…

下载并安装 Latex

因为是开源软件, 所以这个操作起来会比较简单 以下是在 Windows 和 macOS 上从零搭建 LaTeX + VS Code 编辑环境的完整教程，包含安装、配置、测试和常见问题。

Latex 有许多在线编辑器可以使用, 但是我仍然推荐自己安装 Tex 发行版 - 著名的在线编辑器 Overleaf

一、安装 TeX 发行版

TeX 发行版是编译 LaTeX 文档的“引擎”，必须首先安装

Windows 系统

推荐 TeX Live
1. 访问 TeX Live 下载页，点击 install-tl-windows.exe 下载在线安装器。 2. 运行安装器，保持默认选项（建议勾选“为所有用户安装”），直接下一步直到完成。
> 安装过程需要联网下载约 4 GB 文件，请耐心等待 3. 安装结束后，命令行输入 latex --version 验证是否成功。若提示找不到命令，重启电脑使环境变量生效即可。

备选：MiKTeX（轻量按需安装）
- 从 MiKTeX 官网 下载安装包，安装时选择“Ask me first”便于按需安装缺失包。
- 同样可通过 latex --version 验证。

macOS 系统

安装 MacTeX（基于 TeX Live）
1. 访问 MacTeX 官网，下载 MacTeX.pkg（约 4.3 GB）。 2. 双击安装包，按照向导完成安装。
3. 打开 终端，输入 latex --version，若显示版本信息则安装成功。
> 若提示 command not found，执行 sudo /usr/sbin/updatetexmf --quiet 或重启终端。MacTeX 会自动将路径 /Library/TeX/texbin 加入 PATH。

二、安装 Visual Studio Code

两个系统步骤一致：
1. 访问 VS Code 官网，下载对应系统版本（Windows .exe 或 macOS .dmg）。
2. 正常安装并启动 VS Code。

三、安装并配置 LaTeX Workshop 插件

LaTeX Workshop 是 VS Code 最强大的 LaTeX 扩展，提供编译、预览、自动补全、代码片段等功能。

  1. 打开 VS Code，点击左侧活动栏的 扩展 图标（或按 Ctrl+Shift+X / Cmd+Shift+X）。
  2. 搜索 LaTeX Workshop（作者 James Yu），点击 安装。
  3. 安装完成后重启 VS Code
