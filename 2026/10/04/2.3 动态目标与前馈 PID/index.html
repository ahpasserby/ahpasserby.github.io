2.3 动态目标与前馈 PID

Sarzn2026-10-042026-10-04

如果我们让电机对实时变化的角速度进行控制呢? 比如说一个正弦函数? 这是一个动态目标

为了与我们的正弦函数尽可能的贴合, 我们可以引入前馈算法

如果前馈过大, 实际输出会超前于目标, 如果前馈过小, 那么实际输出又会落后与目标

形象理解

F, Feedforward , 前馈

目标变化越剧烈, 我给的提前量预判越多

  • 是前馈系数, 是控制器的参数, 需要手动调节

前馈引入

想象你在练习唱歌,

  • 当你从来没练过的时候, 你只能看着乐谱跟唱:
    • 当前值: 前一时刻自己唱过的内容
    • 目标值: 乐谱上的内容
    • 输出值: 现在自己唱的内容

但是当你越唱越熟练了, 事情开始变得不一样了

当你熟练唱歌的时候, 大概率自己能唱下来了, 一些地方稍微看看谱子就能够顺下去.

这看起来是在当前值和目标值之外, 控制系统好像又引入了一个新的抽象的值, 让你唱的更好了. 这个值中, 暗含了你的唱歌技巧, 你记忆中的谱面

而这些是通过非反馈的机制输入到系统中的

为了区别于反馈, 我们不如叫他为前馈

再来看看 PID 的逻辑

我们为什么需要前馈控制呢?

PID:

  • 一种闭环控制
  • P 控制器, 需要 error 非 0 才能输出, 有差距才有动力, 存在稳态误差
  • I 控制器, 在静态目标时能跟上, 但积分积上去需要时间. 而在频繁变化的动态目标值的情况下, 延迟会显著影响控制系统性能
  • D 控制器, 一直超调, 也需要 error 非 0 时才能起作用

而前馈的作用正是缩短了时间加快了效率

前馈的作用就是让我们有了一定的预判能力, 在我们没用反馈或者弱反馈的情况下, 也能依靠前馈的输出, 在趋势上尽量跟随目标值

  • 弱反馈, 指的是 kp, ki, kd 参数较小的反馈控制器
  • 有了前馈, error 值会变得很小很小, I 控制器积上去需要的所需时间就大幅降低

对于电机

前馈信息与系统的物理模型, 输入系统的目标值有关

对于连续的系统, 前馈的计算方法

  • 前馈信息可以由系统当前时间的输入输出信号的各阶导数计算得出(微分方程的思想)
  • 因为信号的所有阶的导数信息完美复原信号的当前状态(泰勒展开)

对于离散的系统, 前馈的计算方法

  • 前馈信息由系统各个时间点的输入输出信号计算得出
  • 因为各个时间点的输入可以看作差分信息, 极限状态可完美恢复出信号
  • 比如一阶差分与当前和上一时间状态有关, 二阶差分与当前时间, 上一时间, 上两时间状态有关, 以此类推

上述两种是对系统进行建模的做法, 被叫做系统辨识, 也就是向系统输入的各种目标值的波形(目标角, 角速度, 扭矩), 从而观测在这种波形激励下的各种输出(当前角, 角速度, 扭矩等等)

还有一种在 RM 中常见的做法: 基于运动学与动力学的物理建模, 比如底盘的上坡补偿, 云台的重力补偿, 云台根据底盘角速度反向给的一个前馈角速度的小陀螺自稳等等

朴素实现

下面介绍一个极为朴素的, 基于输入信号的前馈思路

场景: 角速度闭环控制(模拟能量机关)

核心思路:

  • 角速度环是由扭矩电流所控制的
  • 扭矩电流与角加速度成正比
  • 角加速度是角速度的差分

角速度环 <- 扭矩电流 <- 角加速度 <- 角速度的差分

以此我们可以绕过角速度环, 直接根据角速度目标值的差分, 乘上一个系数 , 转为扭矩电流, 再把这个扭矩电流和原本 PID的电流叠加到一起, 作为输出电流, 从而对电机进行更好, 更时效的控制了
